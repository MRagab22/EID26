# 🌙 EID Mubarak Card Generator

> A personalized Eid greeting card builder — single HTML file, no backend required.

🔗 **Live Demo:** [https://mragab22.github.io/EID26/](https://mragab22.github.io/EID26/)


---

## ✨ Features

| Feature | Details |
|---------|---------|
| 🧑‍🤝‍🧑 **Personalization** | Enter the recipient's name and your own name |
| 💾 **High-Quality Export** | Save the card as a PNG at 3× resolution via html2canvas |
| 🎊 **Celebration Effects** | Balloons and confetti animate when the card is generated |
| 📱 **Fully Responsive** | Works on all screen sizes |
| 🔡 **Arabic Typography** | Amiri · Cairo · Tajawal fonts with an animated typewriter effect |

---

## 📁 Project Structure

```
EID26/
├── index.html   ← Everything in one file (HTML + CSS + JS)
└── README.md
```

No framework, no build step — just open `index.html` in any browser.

---

## 🚀 How to Use

1. Open the [live site](https://mragab22.github.io/EID26/) or run `index.html` locally
2. Enter the **recipient's name** (required) and your own name (optional)
3. Click **"إنشاء البطاقة"** (Generate Card) and watch it animate to life
4. Click **"حفظ بجودة عالية"** (Save) to download a ready-to-share PNG

---

## 🛠️ Run Locally

```bash
git clone https://github.com/mragab22/EID26.git
cd EID26
open index.html
```

No dependencies to install — everything loads from CDN.
